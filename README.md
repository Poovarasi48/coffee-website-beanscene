# ☕ BeanScene

BeanScene is a modern and visually appealing coffee shop landing page designed to showcase premium coffee products and create an engaging user experience. The website features a clean layout, attractive coffee-themed visuals, and responsive design for seamless browsing across all devices.

## 🌟 Features

* Modern coffee-themed landing page
* Fully responsive design
* Attractive hero section
* Product showcase section
* About Us section
* Customer testimonials
* Call-to-action sections
* Smooth navigation
* Clean and organized code structure

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* ReactJS
